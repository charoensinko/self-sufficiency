# แผน Dev Phase 2 — "Project OS" (เตรียมพร้อมก่อนได้ที่ดิน)

> จัดทำ 2026-07-24 หลังคุยขอบเขตกับผู้ใช้ — อ่านคู่กับ `CLAUDE.md`, `docs/webapp-concept.md` (§6 Dev Phase 2), `docs/HANDOFF.md`

## ข้อสรุปขอบเขต (ยืนยันโดยผู้ใช้แล้ว)

- **สถานะจริง: ยังไม่ได้ที่ดิน** — ทำ Phase 2 ล่วงหน้าเพื่อประหยัดเวลา ดังนั้นทุกโมดูลต้อง**ใช้งานได้โดยไม่ผูกกับแปลงจริง** (ผูกกับ household, เชื่อมกับ `land_candidates` แบบ optional ได้)
- **เอาครบทั้ง 4 โมดูล**: M2 Project Tracker, M7 บันทึกประจำวัน, M4 ปฏิทินปลูก, M3 ผังแปลง
- **แจ้งเตือนในแอปเท่านั้น** (แดชบอร์ด + หน้าโครงการ) — LINE OA เลื่อนเป็นรอบถัดไป
- **แผนแม่บท 10 Phases**: Claude ร่างให้ก่อน (ร่างอยู่ท้ายไฟล์นี้) ผู้ใช้ปรับแก้ แล้วค่อยแปลงเป็น seed
- เพราะยังไม่มีที่ดิน จึง**ไม่ใส่วันที่จริงในแผนแม่บท** — ใช้ระยะเวลาประมาณ (สัปดาห์) ต่อเฟส แล้วค่อยกำหนดวันจริงเมื่อเริ่มเฟสนั้น

## ลำดับ Step (ทำทีละ Step สรุป+รอยืนยันก่อนขึ้น Step ถัดไป เหมือน Phase 1)

### Step 1 — ยืนยันแผนแม่บท 10 Phases
ร่างฉบับเต็ม (งานรายเฟส + milestone) อยู่ที่ `docs/master-plan-10-phases.md` → ผู้ใช้แก้ชื่อเฟส งาน milestone ระยะเวลา → ล็อกเนื้อหาเป็น seed
*ไม่มีโค้ด — จบเมื่อผู้ใช้บอกว่า "ใช้ได้"*

### Step 2 — Schema migration + seed (`00004_project_os.sql`)
ตารางใหม่ (ทุกตารางมี `household_id` + RLS ตาม convention เดิม):

| ตาราง | สาระสำคัญ |
|---|---|
| `project_phases` | ชื่อ, ลำดับ, คำอธิบาย, สถานะ (ยังไม่เริ่ม/กำลังทำ/เสร็จ), ระยะเวลาประมาณ (สัปดาห์), วันเริ่ม–จบจริง (nullable) |
| `project_tasks` | ผูกเฟส, ชื่องาน, รายละเอียด, สถานะ, กำหนดเสร็จ (nullable), `is_milestone` boolean (ไม่แยกตาราง milestone — ลดความซับซ้อน) |
| `journal_entries` | วันที่, เนื้อหา, `photo_paths text[]` (bucket ใหม่ `journal-photos` private + RLS, บีบอัด client ≤1600px ตามเดิม) |
| `crops` | ชื่อพืช, หมวด (ผัก/ไม้ผล/ไม้ยืนต้น/ข้าว/สมุนไพร), อายุเก็บเกี่ยว (วัน), ระยะปลูก, ความต้องการน้ำ, เดือนที่เหมาะปลูก (array), หมายเหตุ |
| `plantings` | ผูกพืช, โซน (ข้อความอิสระก่อน — ยังไม่มีผังจริง), วันปลูกตามแผน/จริง, จำนวน, สถานะ, วันคาดเก็บเกี่ยว |
| `farm_layouts` | ชื่อผัง, ขนาดแปลง (เมตร), `land_candidate_id` nullable, `elements jsonb` (รูปทรงบน canvas) — ทำได้หลายผังไว้เปรียบเทียบ |

Seed: 10 Phases + งาน/milestone จาก Step 1, ฐานข้อมูลพืชเริ่มต้น ~20 ชนิด (ผักอายุสั้น กล้วย ไผ่ ไม้พี่เลี้ยง ข้าว ตามแผนปีที่ 1–2)
**ไม่มีตาราง calendar_events** — ปฏิทินคำนวณจาก `plantings` + `project_tasks.due_date` ตอน query (ลดการ sync ข้อมูลซ้ำ)

### Step 3 — M2 Project Tracker (`/project`) + ปรับเมนู
- Timeline 10 เฟสแนวตั้ง (สถานะ + % งานเสร็จต่อเฟส), หน้ารายละเอียดเฟส: งาน + milestone, ติ๊กเสร็จ, เพิ่ม/แก้/ลบงาน, กำหนดวันเสร็จ
- **แจ้งเตือนในแอป**: การ์ดแดชบอร์ด "งานใกล้ถึงกำหนด/เลยกำหนด" + badge ในหน้าโครงการ
- **ปรับเมนูตามแนวที่คุยไว้ใน HANDOFF**: เพิ่มแท็บที่ 5 "เพิ่มเติม" ใน `nav-items.ts` → หน้า `/more` รวมลิงก์ โครงการ/บันทึก/ปฏิทินปลูก/ผังแปลง/ตั้งค่า (มือถือ); Sidebar desktop แสดงทุกเมนูตรงๆ ไม่ต้องพับ

### Step 4 — M7 บันทึกประจำวัน (`/journal`)
เพิ่ม/แก้บันทึกรายวัน + แนบหลายรูป, รายการเรียงตามวัน, ดูย้อนหลังแบบเดือน — เก็บข้อมูลไว้ให้ AI สรุปใน Step 7

### Step 5 — M4 ปฏิทินปลูก (`/crops`)
- เปิดดู/ค้นฐานข้อมูลพืช, เพิ่มพืชเองได้
- วางแผนปลูก (planting) → ระบบคำนวณวันคาดเก็บเกี่ยว
- มุมมองปฏิทินเดือน: งานปลูก/เก็บเกี่ยว + งานโครงการที่มีกำหนด รวมจอเดียว

### Step 6 — M3 ผังแปลง 5 ไร่ (`/layout`)
- Canvas แบบ **SVG + pointer events** (ไม่เพิ่ม dependency Konva ถ้าไม่จำเป็น — ตัดสินใจจริงตอนลงมือ บันทึกใน decisions.md)
- ลากวางรูปทรงสำเร็จ: สระ/หนอง, โคก, นา, บ้าน, โซนปลูก, ถนน — ปรับขนาด/ตำแหน่ง
- คำนวณอัตโนมัติ: พื้นที่แต่ละโซน, สัดส่วนเทียบ 30:30:30:10, ปริมาตรสระ (พื้นที่ × ความลึก) + ประมาณดินขุด/ถม
- ผูกผังกับแปลงใน Land Finder ได้ (optional) — ใช้ทดลองวางผังบนแปลงที่กำลังพิจารณาซื้อ

### Step 7 — AI + แดชบอร์ด + เก็บงาน + deploy
- Context injection เพิ่ม: สรุปความก้าวหน้าโครงการ (เฟสปัจจุบัน งานค้าง), บันทึกล่าสุด, แผนปลูก — ยึดหลักเดิม "ดึงเฉพาะ field จำเป็น"
- Task ใหม่ใน router: สรุปความก้าวหน้ารายสัปดาห์ (จาก journal+tasks), เตือนงบบานปลาย (เทียบรายจ่ายจริง vs แผนต่อเฟส), แนะนำลำดับงานถัดไป
- แดชบอร์ดปรับการ์ด: เพิ่ม "โครงการ — เฟสปัจจุบัน + งานใกล้กำหนด"
- build + lint + ทดสอบมือถือ + push (auto-deploy)

## Backlog ผังแปลง (หารือ 2026-07-24 — ทำหลังปิด Dev Phase 2)

รูปแปลงจริงไม่เป็นสี่เหลี่ยม / โซนจริงเป็นทรงอิสระ — แนวทางที่ตกลงกัน 2 จังหวะ:

**จังหวะ 1 (ก่อนได้ที่ดิน) — ✅ ทำแล้ว 2026-07-24 (migration 00005):**
- อัปโหลดรูปพื้นหลังเข้า canvas (โฉนด/ภาพดาวเทียม/สเก็ตช์กระดาษ) + ตั้งสเกลด้วย
  "เส้นอ้างอิง 1 เส้น + ความยาวจริง" — bucket `layout-images`
- กรอกเนื้อที่จริงจากโฉนด (ไร่-งาน-วา) ใช้เป็นตัวหาร % แทน กว้าง×ยาว →
  สัดส่วน 30:30:30:10 แม่นโดยไม่ต้องวาดขอบแปลง
- (พ่วง) หน้า `/land/[id]` มีการ์ด "ผังของแปลงนี้" ลิงก์ไป `/layout?id=...`

**จังหวะ 2 (เมื่อได้ที่ดินจริง — เข้าเฟส 2 แผนแม่บท):**
- โซนแบบ polygon แตะทีละจุด + ขอบแปลง polygon ทับภาพดาวเทียม
  (เก็บ `points[]` ใน jsonb เดิม, พื้นที่ด้วยสูตร Shoelace)

**ไม่ทำ:** freehand จริงๆ (สั่น แก้ยากบนจอสัมผัส) และ AI แยกรูปทรงจากกระดาษ
(vision ดึงพิกัดแม่นๆ ไม่ได้) — เป้าความแม่นของเครื่องมือนี้คือ ±5%
พอสำหรับตัดสินใจ/คุยผู้รับเหมา ความแม่นก่อสร้างจริงมาจากงานสำรวจหน้างาน

## สิ่งที่ตัดออกจากรอบนี้ (บันทึกกันหลงประเด็น)

- LINE OA / Messaging API + cron แจ้งเตือน → รอผู้ใช้สั่งรอบถัดไป
- Gantt chart เต็มรูปแบบ → ใช้ timeline แนวตั้งที่อ่านง่ายบนมือถือแทน
- IoT / Smart Farm / Energy ทั้งหมด (Dev Phase 3–4)
- ผูกงบประมาณรายเฟสแบบละเอียด → รอบนี้แค่ AI เทียบภาพรวม ถ้าต้องการ field งบต่อเฟสค่อยเพิ่ม migration ใหม่

## ร่างแผนแม่บท 10 Phases (สำหรับ Step 1 — รอผู้ใช้ปรับแก้)

หลักคิด: เรียงตามหลักโคก หนอง นา — "น้ำมาก่อน ดินตามมา ที่อยู่พออาศัย ปลูกพี่เลี้ยงก่อนพืชหลัก" ระยะเวลาเป็นการประมาณ เริ่มนับจากวันโอนที่ดิน

| # | เฟส | งานหลัก (ตัวอย่าง) | Milestone | ~ระยะเวลา |
|---|-----|--------------------|-----------|-----------|
| 1 | เตรียมการและเอกสาร | โอนกรรมสิทธิ์, รังวัดสอบเขต, ขอมิเตอร์ไฟ/น้ำชั่วคราว, ตรวจวิเคราะห์ดิน-น้ำ, ทำทางเข้าชั่วคราว | โฉนดเป็นชื่อเรา + ผลตรวจดินออก | 4 สัปดาห์ |
| 2 | ออกแบบผังแปลง | สำรวจระดับดิน (contour), วางผังโคก หนอง นา 30:30:30:10 ในแอป, กำหนดจุดบ้าน/สระ/นา, เช็คข้อกำหนดขุดสระกับ อบต. | ผังแปลงฉบับก่อสร้างได้รับการยืนยัน | 3 สัปดาห์ |
| 3 | งานดิน | ขุดสระ/หนอง + คลองไส้ไก่, นำดินขุดถมโคก, ปรับระดับแปลงนา, ทำถนนในแปลง | สระเก็บน้ำได้ + โคกขึ้นรูปเสร็จ | 6 สัปดาห์ |
| 4 | ระบบน้ำ | ปั๊ม + ถังพักน้ำ, เดินท่อเมนรอบแปลง, ระบบสูบจากสระ, บ่อบาดาลสำรอง (ถ้าจำเป็น) | เปิดน้ำถึงทุกโซนได้ | 4 สัปดาห์ |
| 5 | ระบบไฟฟ้าเบื้องต้น | ขอมิเตอร์ถาวร, เดินสายเมน, โซลาร์ชุดแรกสำหรับปั๊มน้ำ, ไฟส่องสว่างจุดสำคัญ | ปั๊มน้ำทำงานด้วยไฟถาวร/โซลาร์ | 4 สัปดาห์ |
| 6 | ที่พักอาศัย | บ้านพักหลังเล็ก/ศาลา, ห้องน้ำ, โรงเก็บเครื่องมือ, ระบบบำบัดน้ำเสียอย่างง่าย | ค้างคืนในแปลงได้สะดวก | 8 สัปดาห์ |
| 7 | ปรับปรุงดิน + ไม้พี่เลี้ยง | ปุ๋ยพืชสด/ปุ๋ยหมัก, ห่มดิน, ปลูกกล้วย ไผ่ และไม้ 3 อย่าง ประโยชน์ 4 อย่าง รอบแปลง, แนวกันลม | ไม้พี่เลี้ยงลงครบทุกโซน | 6 สัปดาห์ |
| 8 | แปลงผลิตอาหาร | แปลงผักอายุสั้น, นาข้าวฤดูแรก, ปล่อยปลาในสระ, เล้าไก่/เป็ดชุดแรก | เก็บผักกินเองได้ครั้งแรก + ดำนาเสร็จ | 8 สัปดาห์ |
| 9 | ย้ายเข้าอยู่ถาวร | ขนย้าย, กิจวัตรประจำวันลงตัว, ระบบขยะ/ปุ๋ยหมักครบวงจร, ความปลอดภัย (รั้ว กล้อง) | พักอาศัยถาวร 100% | 4 สัปดาห์ |
| 10 | เสถียรภาพปีแรก | เก็บเกี่ยวข้าว, ขยายแปลงผัก, บันทึกต้นทุน-ผลผลิตครบรอบปี, ประเมินผล + วางแผนปีที่ 2 | สรุปผลปีแรก: พึ่งตนเองด้านอาหารกี่ % | ต่อเนื่อง 1 ปี |

> หมายเหตุ: เฟส 4–6 บางงานทำคู่ขนานได้จริง — ใน UI จะให้เริ่มหลายเฟสพร้อมกันได้ (สถานะอิสระต่อเฟส ไม่บังคับเรียงลำดับ)
